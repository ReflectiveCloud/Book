# Getting started

---


1. Apply for access using the **[form here](https://forms.reflective.org/cloud-hub-access)**
2. Wait for approval from our team 
3. Explore the platform at **[reflective.2i2c.cloud](https://reflective.2i2c.cloud/)**
4. Check out the for tutorials and examples
5. Join our slack community - use **[this form](https://tally.so/r/A7LyD0)** to apply for access if you are not already added
6. Contribute code and resources


For a quick guide to starting up your server - see **[this video](https://www.loom.com/share/91b458e62ab347ffbd532ac29abf26fd?sid=6366ec4b-f500-45fc-8908-9a273011dfa1)**.
